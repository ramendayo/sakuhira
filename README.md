# Reentry

Reentryは、開発プロジェクトの前回の作業にすぐ戻るためのmacOSアプリです。作業メモとGitの状態を確認し、登録したフォルダやURLをワンクリックで開けます。

## 主な機能

- **ワンクリックで再開** — プロジェクトのフォルダをVS CodeまたはCursorで開き、登録したURLを既定のブラウザで開けます。URLだけの登録にも対応しています。
- **クイック再開** — 設定でショートカットを登録すると、別のアプリで作業中でも検索ウィンドウを開けます。候補をクリックするか、選択して `Enter` を押すと再開できます。
- **作業メモとGitの状態** — 「前回の作業内容」と「次にやること」をMarkdownで残し、Gitのブランチと変更ファイル数を確認できます。
- **プロジェクトの整理** — 名前やフォルダパスで検索し、ピン留めや最終再開日時で探せます。カード・リスト表示と、ライト・ダーク・OS追従に対応しています。

## 起動方法

macOSでソースから起動できます。次の環境を用意してください。

- Node.js 22.12以上の22系とnpm（[.nvmrc](.nvmrc)）
- Rust stable 1.90以上とCargo
- Xcode Command Line Tools（`xcode-select --install`）またはXcode

[TauriのmacOS向けセットアップ手順](https://v2.tauri.app/start/prerequisites/#macos)も参照できます。

リポジトリのルートで実行します。

```sh
npm ci
npm run tauri dev
```

初回はRustの依存関係の取得とコンパイルに時間がかかります。Reentryのウィンドウが開いたら使い始められます。
開発サーバーはポート1420を使います。使用中の場合は、そのポートを空けてから起動してください。

## 基本の使い方

1. 一覧の **「プロジェクトを追加」** を押し、プロジェクト名を入力します。
2. **「フォルダを選択」** で作業フォルダを選びます。開きたいURLがあれば **「起動URL（任意）」** にHTTPまたはHTTPSのURLを入力します。URLだけで登録するときはフォルダを空欄にします。
3. **「登録する」** を押し、一覧で追加したプロジェクトの **「再開」** を押します。フォルダを登録した場合は、設定で選んだVS CodeまたはCursorをあらかじめインストールしてください。URLだけを登録した場合はブラウザが開きます。
